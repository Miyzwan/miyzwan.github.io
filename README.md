# Miyzwan Portfolio (Next.js)

Premium personal portfolio built with Next.js, inspired by Apple-style presentation: clean typography, spacious sections, and polished gradients.

## Tech Stack

- Next.js (App Router)
- React
- TypeScript
- CSS (custom global styling)

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production Build

```bash
npm run build
npm run start
```

## Deployment Notes

This project is deployment-ready for platforms that support Next.js (for example Vercel).

For GitHub Pages, deploy using a Next.js static export workflow only if needed by your hosting strategy.
